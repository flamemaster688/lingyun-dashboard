## 全局筛选（时间 + 省份）
看板所有 Tab 由左侧两张筛选卡片联动驱动：

- **时间筛选**：维度 `月 / 周 / 日`
  - **月**：点选 1–7 月（可多选，形成单月或连续/任意范围），真实汇总 overview / 智能体 / 省份 / 质效 的所选月份数据。
  - **周**：仅适用于「埋点分析」模块（数据源仅含 0720–0726 一周）；其余模块按全周期展示并附说明。
  - **日**：数据源当前未接入日粒度，选择后看板按全周期展示并明确标注缺口。
- **省份筛选（33 单位）**：含 31 个省分中心 + 本部 + 全国。全国=全部；可多选分中心/本部对比。联动所有 Tab（智能体、省份按省份维度真实过滤；总览/质效/埋点为全国汇总，无分省明细时附诚实备注）。
- 「重置筛选」一键还原为全周期 + 全国。报告生成也基于当前筛选。

## 怎么用
1. **看数据**：双击 `index.html`。
2. **筛选**：左侧「时间筛选」选月/周/日与范围；「省份筛选」选全国/本部/各省；所有 Tab 即时联动。
3. **出报告**：报告生成 Tab → 选类型 → 生成（基于当前筛选）→ 下载 .md。
4. **刷新**：重新生成 `data.js` 后点左上「🔄 重新渲染」。

## 怎么刷新真实数据
「数据验证」更新后，重新取数并生成 `data.js`：
```bash
# 1) 用连接器取数（构建脚本__sheet.get_range_data）覆盖 _raw_sheet*.csv
# 2) 汇总生成 data.js
python build_real.py
# 3) 重新打开 index.html（或点🔄重新渲染）
```
> 取数失败的字段统一以「/」显示，缺口说明见看板左侧「缺口备注」与告警 Tab。

## 数据来源：两种方式
看板支持两种数据接入，在左侧「数据源」卡片切换：

**方式一 · 本地文件上传**
- 入口：拖拽文件到上传区，或点击「点击上传」（支持**多文件批量**）。
- 格式：CSV / Excel(.xlsx/.xls) / JSON。
- 大小：单文件上限 **100MB**，超限自动提示并跳过。
- 匹配规则：按**文件名 / 表名**映射到固定看板表——
  `agents/智能体`、`provinces/省份`、`tracking/埋点`、`capability/质效`、`overview/总览`、`alerts/告警`。
  - 上传**一个完整 JSON**（含 overview/agents/... 全部字段）会整体替换数据；
  - 上传**多文件 / 多 Sheet** 则只覆盖识别到的表，其余保留当前数据。
- 列名容错：中英文表头均可（如「调用量/calls」「省份/province」「1月..8月/等效人年」），空值转「/」。
- 「⬇ 下载上传模板」：导出标准 `.xlsx` 模板（多 Sheet，含表头与示例行），照填即可。
- 上传后看板**即时刷新**（无需重新跑脚本或重新部署）。

**方式二 · 离线 Excel（当前模式）**
- 已连接Excel 文件「数据验证」，显示链接、数据截至、最近同步时间。
- 实时同步由**数据维护端（mcp 连接器）**完成：更新文件 → 维护端刷新 `data.js` → 重新部署即生效。
- 纯静态前端受跨域 / 鉴权限制，无法在浏览器里直接读离线 Excel；要做到「粘贴链接即同步」需后端代理（WPS 开放平台 API，V2 路线）。
- 表格解析库已内置 `static/vendor/xlsx.full.min.js`（SheetJS，本地优先 + CDN 兜底）。
