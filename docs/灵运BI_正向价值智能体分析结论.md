# 正向价值智能体分析与平台引导结论

> 数据源：`static/data.js`（灵运 BI 真实数据，智能体 v2 合并，生成于 2026-09-16）
> 分析对象：`agentMonthly` 域（31,850 行，月 × 省 × 应用粒度）
> 判定口径：以「应用(appId)」去重；当某智能体在任一月份出现 `positiveValue=1` 即判定为**案例级正向价值**（与看板"是否有正向月份"口径一致）。价值字段（节约金额 / 产生真实价值）仅在 6–8 月有认定，1–5 月源表本就为空，属真实口径而非缺失。

---

## 一、总体发现

| 指标 | 数值 |
|---|---|
| 智能体总数（去重 appId） | 4,972 |
| 正向价值智能体（含正向月份） | 246 |
| 正向占比 | **4.9%** |
| 节约金额：全部 / 正向贡献 | 4.075 亿 / 4.072 亿（**99.9%**） |
| 产生真实价值：全部 / 正向贡献 | 3.943 亿 / 3.945 亿（**100.0%**） |
| 正向价值时间分布 | 仅 6 月(220)、7 月(247)、8 月(217) 有认定 |

**一句话结论**：平台 95% 的智能体在价值计量口径下"不产生可衡量的正向价值"，而 4.9% 的正向智能体贡献了几乎全部（≈100%）的节约金额与真实价值。**价值极度头部化，且高度依赖单点。**

## 二、正向价值智能体的「类型」画像

> 维度字段：`type`

| 类型 | 智能体数 | 正向数 | 正向率 | 节约金额累计 | 真实价值累计 |
|---|---|---|---|---|---|
| **工作流** | 3,420 | 162 | 4.7% | **3.842 亿（94.3%）** | 3.727 亿 |
| **智能体** | 1,513 | 84 | **5.6%（最高）** | 0.230 亿 | 0.218 亿 |
| 对话流 | 39 | 0 | 0.0% | 0 | 0 |

**结论**：
- **「工作流」是价值主引擎**——占据 94% 的正向价值，是规模化复制的承重墙。
- **「智能体」命中率最高（5.6%）**，单位投入更易跑通价值，是"精兵"型选择。
- **「对话流」零正向价值**——在当前计量口径下未产生任何节约/真实价值，应停止在其上投入价值预期，或转为内部体验用途。

## 三、正向价值智能体的「分类」画像

### 3.1 服务环节（servicePhase）—— 命中率与体量的错位

| 服务环节 | 智能体数 | 正向数 | 正向率 | 节约金额累计 |
|---|---|---|---|---|
| 服务后 | 3,318 | 176 | 5.3% | 0.820 亿 |
| **服务前** | 187 | 36 | **19.3%（最高）** | 0.052 亿 |
| 服务中 | 1,283 | 34 | **2.7%（最低）** | **3.200 亿（78.6%）** |
| 其他 | 184 | 0 | 0.0% | 0 |

- **服务前 = 最高命中率（19.3%）**：以"重复来电(19.3%)、境外来电(28.6%)"为代表的**预判/前置拦截**场景，投入少、跑通概率高，是性价比最高的孵化方向。
- **服务后 = 价值基本盘（5.3%、176 个正向）**：以"服务质量稽核、工单查证"为主的质检稽核场景，是规模化产出的稳定来源。
- **服务中 = 体量最大但命中率最低（2.7%）**：78.6% 的价值集中于此，但**几乎全部来自单一巨型智能体（桂启营）**，属"单点赌博"而非可复制方向，不应作为普适引导路径。

### 3.2 应用场景（appScene）—— 已被验证的"黄金场景族"

| 应用场景 | 智能体数 | 正向数 | 正向率 |
|---|---|---|---|
| **境外来电** | 28 | 8 | **28.6%（最高）** |
| **重复来电** | 187 | 36 | 19.3% |
| **退费稽核** | 76 | 10 | 13.2% |
| **工单查证** | 416 | 44 | 10.6% |
| 静默分析 | 46 | 4 | 8.7% |
| **服务质量稽核** | 764 | 65 | 8.5% |
| 不满意度分析 | 114 | 9 | 7.9% |
| 话务与数据分析 | 1,855 | 35 | 1.9% |
| 坐席与营销辅助 | 1,267 | 33 | 2.6%* |

\* 坐席与营销辅助正向率仅 2.6%，却贡献 3.199 亿节约（78.5%），**完全由桂启营单点撑起**，不可作为"该场景普遍高价值"的证据。

**结论**：高频正向场景清一色属于 **"稽核 / 查证 / 预判 / 分析"** 四类专业属性——即**用 AI 替代或增强人工的合规质检与风险拦截**。这是平台已被数据验证的黄金场景族。

### 3.3 推广场景（promoScene）—— 人工策展 ≈ 必出价值

| 推广场景 | 智能体数 | 正向数 | 正向率 |
|---|---|---|---|
| 工单查证 | 8 | 8 | **100%** |
| 携转挽留监控 | 3 | 3 | **100%** |
| 重复来电 | 32 | 27 | 84.4% |
| 静默分析 | 3 | 2 | 66.7% |
| 不满意度分析 | 14 | 9 | 64.3% |
| 退费稽核 | 10 | 6 | 60.0% |
| **（空 / 自然生长）** | 4,901 | 191 | **3.9%** |

**结论**：被平台**主动策展、定向推广**的场景，正向率（60%–100%）是自然生长场景（3.9%）的 **15–25 倍**。这是最强证据——**"精选场景 → 模板化 → 推广"的路径几乎必出价值**，放任自由生长则九成以上沦为零价值长尾。

### 3.4 能力标签（tags）—— 正向智能体的能力内核

正向智能体标签词频 Top：**服务提升(109)、AI稽核(37)、归纳总结(32)、效能提升(30)、诉求预判(15)、营销转化(13)、信息查证(7)**。

**结论**：价值内核集中在 **AI 稽核、自动归纳总结、效能提升、诉求/意图预判** 四类能力。这四类是"让智能体产生可计量价值"的最小能力集。

## 四、价值分布：极度集中 + 省份孤岛（关键风险）

1. **头部极端集中**：Top1 单智能体（桂启营·广西·坐席与营销辅助）独占全国正向节约的 **65.1%**；Top5 占 79.9%，Top10 占 85.1%。
2. **省份孤岛**：同名智能体 4,871 个，仅 128 个（2.6%）跨 ≥2 省，且跨多省的几乎都是"测试"类或低价值复制；真正跨省且正向的极少。桂启营**仅在广西一省**产出 2.65 亿价值，**优秀模式没有被复制到其它省份**。
3. **LLM 是放大杠杆**：行级看，isLLM 行仅占全部行的 8.1%，却贡献了 86.8% 的正向行——LLM 类智能体一旦跑通，跨省份批量复制能力极强（一个 LLM agent 在多省生成多份正向记录）。

## 五、战略引导结论：平台智能体该往哪走

### 方向一 · 类型选择
- **主力用「工作流」规模化承重**（已证 94% 价值）；
- **用「智能体」做高命中率精兵**（5.6% 最高正向率）；
- **停止在「对话流」上设定价值目标**。

### 方向二 · 场景族选择（建什么）
聚焦已被验证的"稽核 / 查证 / 预判 / 分析"黄金场景族，优先级：
1. **服务前预判拦截**：重复来电、境外来电、诉求预判（命中率 19%–29%，投入小产出高）；
2. **服务后质检稽核**：服务质量稽核、工单查证、退费稽核、不满意度分析（稳定基本盘，正向数最多）；
3. **静默分析、携转挽留**等细分高危场景（高正向率，适合做标杆）。

### 方向三 · 服务环节节奏
- **优先孵化服务前**（最高命中率，快速见效）；
- **规模化服务后稽核**（基本盘）；
- **服务中不作为普适方向**（价值依赖单点，风险集中）。

### 方向四 · 能力内核
所有新建/改造智能体应以 **AI 稽核 + 自动归纳总结 + 效能提升 + 诉求预判** 为能力最小集，围绕"可计量价值"而非"调用量"设计。

### 方向五 · 平台机制（怎么管）
1. **从"数量"转向"达标率 + 价值密度"**：用 4.9% 正向率作为健康度标尺，而非智能体总数。
2. **策展推广优先于自由生长**：把高正向率场景（重复来电/工单查证/退费稽核等）做成**官方模板**定向推广，复制 15–25 倍的正向率优势。
3. **打破省份孤岛**：把桂启营、各省头部稽核工作流抽象为**跨省份可复用模板**，主动推给其他省，把"单点 65%"变成"全省 65%"。
4. **放大 LLM 杠杆**：优先用 LLM 承载可跨域的稽核/预判场景，利用其天然的多省复制能力。
5. **固化价值计量口径**：正向价值目前仅 6–8 月有认定，需让新建智能体**从上线即纳入节约金额/真实价值评估**，避免前期盲区。
